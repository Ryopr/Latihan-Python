# Read Me

Ini merupakan contoh latihan python yang dibuat dan dilakukan oleh Jasa Pribhuni. Pada latihan ini terdapat sejumlah sesi seperti berikut:

- **Latihan 1** — penggunaan python secara biasa
- **Latihan 2** — looping for dan while, switch case
- **Latihan 3** — import data excel, membaca sejumlah file excel di dalam suatu folder lalu menyatukannya
- **Latihan 4** — membuka dan membersihkan data-data `Rp. 0,00` di bawah 80% Nilai HPS menjadi seperti berikut ini `Rp. 0,00`
- **Latihan 5** — melakukan importasi header data, membuat tabel PostgreSQL dengan Prisma ORM, dan melakukan parsing data (dengan membuang `"Rp. "`, `"."`, dan merubah `","` jadi `"."`) agar data dapat dikelola di database
- **Latihan 6** — mengimport data ke PostgreSQL, membuat model interaksi dengan Prisma, dan membuat script utama. Jika sempat, sekalian membaca data dari PostgreSQL
- **Latihan 7** — membaca satu folder berisi banyak file, lalu mengirimnya secara looping agar dapat dibaca di PostgreSQL
- **Latihan 7a** — menggabungkan script Latihan 4 sampai Latihan 7:
  - melakukan truncate tabel, melakukan set id jadi 1 lagi
  - menambah fitur agar setiap data yang telah di-cleansing dan parsing tidak diproses ulang dan menyebabkan angkanya berubah, namun langsung diimport saja ke PostgreSQL
- **Latihan 8** — image filtering
- **Latihan 8a** — massive image filtering dan penggunaan Tesseract OCR untuk solving captcha
- **Captcha text preparation** — dengan bantuan Gemini AI API dan penggunaan git serta GitHub
- **Latihan 12** — memodifikasi dokumen dari python `docxtpl`, siapkan pip list di `requirement.txt`, dan lanjut git
